# TZ Board

Timezone dashboard built for MSPs. Shows live clocks for multiple locations — designed to run on an office TV.

**Live:** https://lachlanalston.github.io/tz-board/

---

## How it works

Open the builder, add clocks, hit **Generate Dashboard Link**. Paste the link into any browser or TV.

Config lives entirely in the URL — no backend, no login, no account. Share the link and it just works.

---

## Layouts

Adapts automatically based on how many clocks you add (1–8).

---

## Timezones

110+ cities and regions across Americas, Europe, Africa, Middle East, Asia, Russia, and Oceania. Search by city name or region. Custom IANA timezones also supported.
